1.JS的组成部分？
    三大部分:
    ECMAScript(我们常用的let const 箭头函数 核心点) 
    BOM(浏览器对象模型 如setInterval/console) 
    DOM(文档对象模型 如document.querySelect)

2.JS的内置对象有哪些？
    String Boolean Number Object Function Array
    Math Date RegExp Promise JSON Map Set Error Symbol

3.JS操作数组的方法有哪些？
    第一组：push pop unshift shift 
    splice(任意位置增删改) splice(a,b,c,d...) 表示从下标a开始，删除b个元素，并按顺序插入c,d... 
    slice(截取一段，不改变原数组)

    第二组：forEach map filter 
    find（找到第一个符合的元素并返回） findIndex（找到第一个符合的元素并返回其下标）
    some（返回布尔值 表示数组中是否有元素满足条件） every（返回布尔值 表示数组中是否所有元素满足条件） 
    reduce（累加器） reduce((sum,cur)=>{ return xxx},init) init为sum的初始值 sum为目前的累加值 cur为当前元素

    第三组：indexOf(根据简单值查找下标) includes(根据简单值查找是否有) sort reverse

    第四组：concat(合并数组) join(数组变为字符串) split(字符串变为数组) 
    flat(数组扁平化 展开深层数组) Array.from(把类数组转为数组) Array.isArray(判断是否为数组)

4.JS对数据类型的检测方法有哪些？
    typeof 检测基本数据类型（对于null返回的是object，对于数组/对象返回的都是对象，对于函数返回的是函数）
    instanceof 检测是否属于某构造函数的实例（原型链原理 有很多失误点）
    constructor 判断正确 但极易被修改
    Object.prototype.toString.call 最全能的方法 基本不会出错 会以 '[object xxx]'的形式出现 xxx即为数据的类型
    Array.isArray 专门用于检测数组

5.简单说一下闭包？闭包有什么特点？
    闭包即为外层函数包裹内层函数 并且内层函数指向外层函数内的变量 外层函数返回内层函数
    闭包外层函数内的变量不会被回收 因为被返回的内层函数一直指向
    特点：
    1.外层函数变量被保护，外部无法直接修改或访问  
    2.被返回的内层函数可以以外层函数内的变量作为参数，无需每次传递较多参数
    3.内存占用较大 性能开销较大 （还有一个经典坑--循环陷阱）


6.前端的内存泄漏该怎么理解？有哪些常见的内存泄漏点？
    内存泄漏：有一些我以后永远用不到的变量仍旧被存储 JS垃圾回收机制没有清除
    常见的情况：事件未解绑 定时器未关闭 闭包过多 幽灵节点（删除节点 但变量未制空） 变量挂载到windows身上
    可以观察 性能面板 和 内存面板 以确认内存泄漏

7.事件委托是什么？
    当很多子元素需要绑定同一事件的时候 为了节省绑定事件的次数与性能消耗 我们通常把事件绑定在父元素身上
    这样减少了性能消耗 利用事件冒泡的机制 正常触发子元素的事件
    而且如果是ajax动态渲染数据 多出的一条数据的事件不用重新绑定 因为父元素会帮忙触发事件
    深层嵌套使用closest 并不是所有事件 如focus blur 是没有事件委托的

8.基本数据类型和引用数据类型？
    基本数据类型直接在栈内存中存值 如number string boolean
    引用数据类型则是在栈内存中存放地址 其指向堆内存中的某一块区域 在堆内存中存放实际值 如function object array
    栈的优势在于访问速度快 缺陷在于大小固定 不灵活 由函数作用域管理变量
    堆的优势在于大小不固定 可灵活拓展 但访问速度较慢 由GC机制管理变量

9.简单说一下原型链？
    构造函数会有原型 也会有实例 实例的__proto__和构造函数的prototype都会指向原型
    原型身上的所有属性和方法都可以被其下方的实例访问到
    实例通过原型链去一步步查找原型 最终会找到Object 再往上即为null 原型链到底

10.new操作符具体做了一些什么？
    1.创建一个新的对象  2.将构造函数中的this指向新创建的对象 
    3.将新的对象的__proto__指向构造函数的prototype  
    4.判断一下构造函数中是否有手动return一个引用类型数据，如果有则返回该数据；如果没有，则返回这个新造的对象

11.JS如何实现继承？
    1.直接用原型链进行继承： 构造函数的原型手动指向其父类的实例 完成了方法的继承 最好使用Object.create(Parent.prototype)
    2.在子构造函数中调用 父构造.apply(this，args) 使得父构造函数中的this指向了子构造函数实例对象 完成了属性的继承
    3.上述两种方法共同使用的组合继承，完成了方法和属性的共同继承
    4.class方法：extends 和 super  ES6之后组合继承的语法糖 

12.JS的设计原理是什么？
    JS引擎：v8引擎（了解） 对JS代码进行语法解析 通过编译器将JS代码转为机器码 供机器执行
    运行上下文：浏览器可调用的API 如BOM DOM提供的API 这些外部的接口可以在运行的时候提供给JS进行使用
    调用栈：单线程 若有阻塞直接卡死
    事件循环：当调用栈空时 循环执行宏任务和微任务
    回调：不立刻执行的函数 满足某一条件的时候执行 是异步一开始的实现方式

13.JS中的this指向问题？
    1.普通函数的this指向windows（严格模式是undefined）；
    2.对象中方法的this指向调用对象（谁调用函数，this就指向谁）；
    3.构造函数中的this指向实例对象（new操作符的特性）；
    4.箭头函数没有this，它的this继承外层函数的this

14.script标签里的async和defer的区别是什么？
    当普通的script标签出现时 由于JS是单线程 浏览器会立刻下载并执行该script脚本 后续渲染卡住
    当加上async（异步）时 异步加载资源 加载资源和渲染后续内容同步进行 且资源下载完毕之后立刻执行 执行时会阻塞渲染
    当加上defer（延迟）时 异步加载资源 加载资源和渲染后续内容同步进行 且资源下载完毕之后等待浏览器渲染完毕之后再执行 确保DOM加载完毕

15.setTimeout和setInterval的最小执行时间是多少？
    ECMA标准并未明确规定 各个浏览器略有不同
    setTimeout最小时间是4ms（嵌套大于等于5层时  嵌套较小时约为1ms） setInterval最小时间是10ms

16.ES6和ES5有什么区别？
    ES5是ECMA2009 ES6是ECMA2015 
    ECMA2015往后被统称为ES6+（因为2015版本之后 官方不再以数字而是年份命名ECMA）

17.ES6的新特性有哪些？
    1.变量声明：let和const 解决了var声明混乱的问题 增加块级作用域
    2.箭头函数：各种简写方式 this继承特性 
    3.代码更加简洁：模板字符串 解构赋值 展开运算符
    4.异步解决方式：异步的实现方式由回调函数改变为 Promise和async/await 解决回调地狱问题 
    5.模块化： 原生支持import和export
    6.类：构造函数和继承不再手写 class extends super 但底层还是原型链
    7.数据结构：Map，Set

18.call apply bind三者的区别是？
    三者都用于改变调用者中this的指向 其中call和apply类似 立即调用 只是call传递参数得一个个传 而apply传递参数则是一个数组包裹起来传
    bind稍有不同 不立刻调用函数 而是返回给你一个改变了this指向的函数 你可以后期随时调用

19.用递归的时候需要注意的问题？
    递归：函数在函数体内调用自己的写法
    注意点：一定要由函数的出口 不然会导致栈溢出；性能开销较大，比循环慢；
    递归如果深度过大，有出口也会爆栈；大深度场景还是建议改为循环实现；

20.如何实现一个深拷贝？
    1.展开运算符（但只能深拷贝一层，嵌套对象仍旧共用一块地址） 
    2.JSON的parse和stringfy（但无法处理undefined，symbol等一部分特殊类型）--- 开发中常用于简单数据的深拷贝
    3.structuredClone（obj）（原生API 无法复制函数）--- 开发中常用于各种数据额深拷贝
    4.手写递归函数（后面需要准备的手写题）
    实际场景中我们一般不会对函数进行深拷贝 因为这没什么意义

21.简单说一下事件循环？
    JS是单线程的 拥有调用栈和任务队列
    其中调用栈会优先放入同步代码 而任务队列（宏任务队列和微任务队列，分开存放）则会存放宏任务和微任务（都是异步）
    先清空调用栈中的同步代码 然后把所有微任务清空 最后挑一个宏任务执行
    一次反复执行 这个过程就是事件循环
    宏任务：比如定时器 IO 网络请求（ajax，fetch） 绑定的DOM事件 UI渲染
    微任务：比如promise.then() await/async fetch.then()
